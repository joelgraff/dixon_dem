# Post-Scene Dossier

After each scene ends, the player gets a one-page summary styled like a period newspaper or a historian's note. It lays out what shifted because of what they did. Saved the bridge → dossier mentions the mill that stayed open, the family that didn't leave town. Let Smith go west → it notes the temple that never rose.

## Dual purpose

The same text that tells the story to the player is the record the spec branch needs. Canon documentation and player-facing consequence summary are one artifact.

## Format sketch

```
[DATE] — [SCENE NAME]
Headline: what the player did
Body: 2-4 sentences of consequence
Survivors/changed: named NPCs and bloodlines affected
Next anchor: where the timeline reconverges
```
