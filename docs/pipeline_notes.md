# Data pipeline notes (for other workstreams)

Generated by `pipeline/build_all.py`. Full details/formats: `pipeline/README.md`.
Rerun anytime with `cd pipeline && ../.venv/bin/python build_all.py`.

## Where things are

All consumable outputs are in `game/data/`:

| file | contents |
|---|---|
| `world_origin.json` | origin (UTM 26916), base elevation, heightmap dims/spacing, river pool levels |
| `heightmap_play_1m.r32` | 2700x2700 @ 1m, hydro-flattened, **not** road-conformed |
| `heightmap_play_1m_road_conformed.r32` | same, + roads carved flat (~2% camber) |
| `heightmap_horizon_12.5m.r32` | 800x800 @ 12.5m, 10x10km, distant terrain |
| `roads.json` | road centerlines + per-vertex Y + `junction_nodes` (intersections) |
| `rails.json` | railway centerlines |
| `bridges.json` | all bridge segments (roads + rails), deck heights pre-computed |
| `buildings.json` | footprints, ground Y min/max, `height_m` estimate, landmark IDs |
| `water.json` | flat river/pond reach polygons (`surface_y`), streams, dam lines |
| `landuse.json` | parks/grass/wood/etc. polygons |
| `pois.json` | amenity/historic/tourism points, incl. Lincoln statue, Dixon arch |
| `trees.json` | `natural=tree` points (sparse -- OSM coverage is thin) |
| `lamps.json` | **empty** -- no street lamps mapped in OSM for Dixon |
| `power.json` | overhead power lines clipped to the play area and mapped support nodes |

`.r32` = raw float32 little-endian, row-major, row 0 = north edge. Value =
`elevation_m - base_elevation_m` (already Godot-local Y). See
`pipeline/README.md` for exact dims/origin per grid (also in
`world_origin.json`).

## Coordinates

Godot local space: `x` = east (meters), `z` = `-(northing - origin_northing)`
(north is -Z), `y` = `elevation_m - base_elevation_m`. UTM 16N (EPSG:26916).
Origin: easting 292300, northing 4634000. Play area is a 2700x2700m square
(`[292300,4634000]` to `[295000,4636700]` in UTM), base_elevation_m = 192.0.

## Elevation range

Play area: 192.5 - 233.4 m absolute (local Y 0.5 - 41.4). Horizon (10km):
193.5 - 256.6 m absolute (local Y 1.5 - 64.6).

## River / pool elevations (local Y)

- `river_upstream` (north of dam): 5.92 (197.92 m absolute) -- Van Arnam Island
  sits mid-channel in this reach; the reach polygon is punched with a hole for
  the island and may export as multiple ring pieces (channel arms either side
  of it), all sharing this pool level.
- `river_downstream` (south of dam): 3.54 (195.54 m absolute) -- ~2.4m drop across the dam
- Van Arnam Island's own inner lagoon/pond: 5.93 local Y (kept as water, island itself is dry DEM terrain)
- 2 other small ponds nearby: 6.46, 20.38 local Y

## Known issues (see pipeline/README.md "Known issues" for full detail)

- **Fixed 2026-09-17**: Van Arnam Island and the Willow Park islet were
  briefly missing from water.json (river polygon covered them solid,
  flattening their terrain) -- both are now correctly subtracted from the
  river (island terrain keeps raw DEM elevation), while Van Arnam's own inner
  lagoon stays as water. Dam-side reach splitting also switched from a
  raster-only mask to an accurate vector polygon split.
- `nachusa_house` position is interpolated, not a verified address match.
- `lamps.json` is empty; no street lamps mapped in OSM for this area.
- Power-line and support rendering is documented in
  [infrastructure_notes.md](./infrastructure_notes.md); the power export must
  be regenerated after fetching `osm_power.json`.
- Van Arnam Island's NE tip and Page Park's west edge extend slightly past
  the play-area square (still covered by the wider OSM fetch + horizon grid).
- DEM source is 2008-2009 LIDAR; anything built/regraded since then is only
  as current as OSM's mapping, not the terrain.
