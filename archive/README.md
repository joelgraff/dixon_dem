# Archive

Retired work, kept for reference. Nothing here is built, tested or served.

- **pipeline-prototype/**: the lighthouse experiment for the Sierra-style
  renderer. A Python text parser (`lighthouse_parser`) that generated SCI-style
  vocabulary resources, and an EGA art pipeline (`lighthouse_art`) that turned
  scene cards into 320x200 palette-enforced plates. The text adventure is now
  the browser engine in `docs/play.js`, playing the scene-card data in
  `docs/game-data` (format: `docs/game-data/FORMAT.md`).
- **sierra-parser/**: planning notes for the Sierra-style 2.5D parser renderer
  (from the `sierra-parser` branch), formerly `docs/sierra-parser`. The
  historical research in it is still useful; the plans were superseded by the
  same scene-card format and engine.

Both were archived on 2026-11-06. The branches of the same names are untouched.
